# 모여락 사용자 🏃‍♂️🏋️‍♀️
## 📢 프로젝트 소개
‘모여락’은 ‘모여라’ + ‘Lock’의 합성어로, 사람들이 몰리는 시간에도 안정적으로 예약을 Lock한다는 의미를 담고 있습니다.
공공 체육시설은 정기 등록일이나 주말 저녁 등 예약이 몰리는 시간대에 시스템 지연과 예약 실패 문제가 자주 발생합니다.
‘모여락’은 피크타임에도 안정적으로 사용자 예약을 관리하고, 운영자는 실시간 트래픽과 피드백을 기반으로 자동화된 운영 관리까지 가능한 클라우드 기반 스마트 예약 플랫폼입니다.

## 🎯 프로젝트 목표
- 반복되는 서비스 지연, 중복 처리, 운영 비효율 해결
- 유연한 확장성 확보와 트랜잭션 무결성 보장
- 자동화된 운영 관리 시스템 단계적 구현
- 사용자 행동 기반 개선 피드백 및 리포트 자동화
- 실제 운영 가능한 수준의 MVP 구현

## 🛠️ 주요 기능
- 체육 시설 조회
- 프로그램 신청
- 공지사항 조회
- 내 정보 수정
- 수강 신청 내역 확인
